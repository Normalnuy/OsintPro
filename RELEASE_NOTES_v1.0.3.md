# Justin OSINT v1.0.3

## ✨ Нові можливості

- **Justin Phone OSINT** — власний модуль аналізу телефонів (замість PhoneInfoga): оператор, формати, dork-згадки
- **Telegram / VK / LinkedIn** — окремі OSINT-сканери в блоці соцмереж
- **Архів** — повторний пошук (↻ Оновити), порівняння двох досьє, пошук по ІПН/телефону/ніку
- **PDF** — експорт звіту прямо з екрана результатів пошуку
- **Кеш** — налаштування TTL, розмір, кнопка «Очистити кеш»
- **Оновлення** — перевірка з головного вікна; лаунчер оновлює себе автоматично
- **Playwright bootstrap** — встановлення Chromium при першому запуску

## ⚙️ Стабільність

- Збереження параметрів пошуку в досьє (`SearchSnapshot`) — без дублікатів при оновленні
- Індекс архіву за `{id}.json` — швидший пошук
- Sentry DSN застосовується без перезапуску програми
- Прогрес завантаження оновлень у лаунчері (%, МБ)

## 🧪 Якість

- 26 unit-тестів
- CI: збірка + zip з лаунчером
